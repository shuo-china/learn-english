# 词汇森林宣传 PPT 大纲

面向对象：评委 / 投资人  
建议时长：5-8 分钟  
建议页数：12 页  
视觉方向：温暖手绘动画电影感，强调自然、纸张、森林、微光、童话式学习场景；不直接复刻任何在世艺术家的具体画风。

## 1. 封面：词汇森林 Vocabulary Forest

核心文案：让背单词变成一次会发光的森林冒险。

讲述重点：
- 这是一个面向学生的沉浸式英语词汇练习 Web App。
- 产品把“背词”从机械任务变成更温和、更愿意重复进入的学习场景。
- 开场先建立情绪记忆点：森林、词书、微光、探索。

视觉建议：
- 晨雾森林作为全屏背景。
- 画面中心是一册打开的词书，英文单词像萤火微光一样飘出。
- 标题使用温暖米白或浅金色，副标题轻一些，保留呼吸感。

备注：
- 这一页不堆功能，先让评委记住“词汇森林”的产品气质。

## 2. 痛点：传统背词为什么难坚持

核心文案：学生不是不想学，而是缺少一个愿意每天回来练习的环境。

讲述重点：
- 传统单词表容易变成机械记忆，缺少情绪上的正反馈。
- 普通测试反馈滞后，学生很难立即知道自己哪里会、哪里不会。
- 很多工具只解决“记单词”，没有把“识记、回忆、拼写、反馈”串成闭环。
- 移动端体验割裂时，碎片时间练习会变得很难坚持。

视觉建议：
- 左侧是灰色、拥挤的传统单词表。
- 右侧透出森林微光，暗示新的学习入口。
- 使用 3-4 个短痛点标签：枯燥、反馈慢、易放弃、难复习。

## 3. 产品定位：沉浸式英语词汇练习工具

核心文案：一款轻量、可扩展、跨设备的词汇学习 Web App。

讲述重点：
- 当前产品基于 Vue 3 + Vite 构建，打开网页即可使用。
- 学习路径分为两条：背诵识记和拼写巩固。
- 用户可以选择词书，并在顺序和随机练习之间切换。
- 产品重点不是“堆功能”，而是让学生稳定完成一次又一次有效练习。

视觉建议：
- 用一张简洁产品地图展示：词书选择 -> 背诵模式 / 拼写模式 -> 反馈 -> 下一轮练习。
- 背景保持温暖纸张质感，像森林地图。

## 4. 核心体验一：像翻开森林里的词书

核心文案：先看见单词，再轻轻揭开意思。

讲述重点：
- 背诵页展示单词列表，英文始终可见，中文释义默认被柔和遮罩隐藏。
- 学生点击后揭示释义，同时触发发音，形成“看词、猜义、确认、听音”的记忆动作。
- 重点词通过高亮区分，方便把注意力放在更关键的内容上。
- 这种低压力交互适合预习、快速浏览和课后复习。

视觉建议：
- 展示纸页式单词列表。
- 中文释义区域用雾化光斑或半透明叶影表示“待揭示”。
- 重点词像被阳光照到的树叶，轻微金色高亮。

## 5. 核心体验二：拼写闯关式主动回忆

核心文案：从“看过”走向“写得出”。

讲述重点：
- 拼写页根据中文释义要求学生输入英文，训练主动回忆。
- 多词短语会被分段处理，学生能逐段完成，不会被长答案一次性压垮。
- 输入正确后锁定，错误时即时标红，连续错误后可显示答案。
- 完成后展示英文与中文释义，并播放正确反馈音效。

视觉建议：
- 草地背景上放置一张温暖练习卡片。
- 单词字母像小路上的石板，正确段落变成绿色，错误段落变成柔和红色。
- 右上角可放进度数字，强化闯关感。

## 6. 学习闭环：听、看、想、拼、反馈

核心文案：一次练习，完成一轮完整的记忆加固。

讲述重点：
- 选择词书：花林物语、考研词汇、西游记词汇等不同内容入口。
- 选择顺序或随机：既支持系统学习，也支持打乱检测。
- 背诵阶段：看词、猜义、揭示、听发音。
- 拼写阶段：看中文、主动回忆、输入英文、获得即时反馈。
- 反馈阶段：正确音效、错误音效、答案提示和下一题推进。

视觉建议：
- 用环形流程图表现：选词书 -> 识记 -> 发音 -> 拼写 -> 反馈 -> 复练。
- 环形中心放一粒发光种子，暗示记忆逐步生长。

## 7. 差异化：情绪友好的学习界面

核心文案：把学习压力转化为安静、持续、愿意停留的体验。

讲述重点：
- 产品界面不是冷冰冰的表格，而是森林、草地、纸张和手写感的学习空间。
- 中文使用楷体气质，英文使用圆润字体，降低视觉压迫感。
- 控件像纸页和木牌，反馈像自然中的提示，而不是考试式打击。
- 音效让每一次输入和判断都有轻量反馈，增强沉浸感。

视觉建议：
- 将 UI 元素拆解为四个关键词：森林背景、纸张卡片、圆润控件、温和反馈。
- 可用四宫格展示对应截图或示意画面。

## 8. 内容体系：多词书可扩展

核心文案：词库格式简单，内容可以持续生长。

讲述重点：
- 当前已有词书包括：花林物语、考研词汇、西游记词汇。
- 词库采用简单文本格式，便于维护、替换和扩展。
- 后续可以扩展校本词库、考试词库、阅读主题词库、教材同步词库。
- 对学校和机构来说，这意味着部署成本低、内容适配灵活。

视觉建议：
- 一棵“词书树”：树枝分别长出不同词书。
- 每本词书像一张小书签，挂在树枝上。

## 9. 技术实现：轻量、可部署、跨设备

核心文案：用轻量 Web 技术承载稳定的学习体验。

讲述重点：
- 技术栈：Vue 3、Vite、Vue Router。
- 页面模块清晰：背诵页、拼写页、词库解析、发音与音效模块。
- 本地静态词库便于部署，也方便后续接入云端数据。
- 已做移动端适配，包括小屏词书选择弹窗和拼写输入处理。
- Web 形态适合课堂投屏、电脑练习和手机碎片化使用。

视觉建议：
- 用简洁技术架构图展示：词库文件 -> 解析模块 -> App 状态 -> 背诵 / 拼写页面 -> 发音与音效。
- 保持评委可理解，不堆代码细节。

## 10. 应用场景：课堂、课后、自主学习

核心文案：同一个工具，覆盖不同学习时刻。

讲述重点：
- 课堂预热：老师投屏展示词书，快速带学生熟悉新词。
- 课堂检测：切换随机顺序，进行快速拼写抽查。
- 课后复习：学生在手机上完成短时练习。
- 自主学习：学生按自己的节奏揭示释义、重听发音、反复拼写。

视觉建议：
- 三个场景并列：教室投屏、课后书桌、手机碎片练习。
- 每个场景用一句短价值表达：老师好组织、学生好开始、复习好坚持。

## 11. 增长空间：从词汇工具到学习陪伴系统

核心文案：词汇森林可以继续长成一套学习陪伴系统。

讲述重点：
- 学习数据：进度记录、练习次数、正确率趋势。
- 错词体系：自动收集错词，生成个性化复习路径。
- 记忆曲线：根据遗忘规律安排复习节奏。
- 教师端：班级词库、练习布置、学习报告。
- AI 能力：例句生成、语境解释、发音评分、个性化提示。

视觉建议：
- 从当前产品出发，画成一条向森林深处延伸的小路。
- 路标依次写：错词本、记忆曲线、教师端、AI 练习伙伴。

## 12. 结尾：让每个单词都有被记住的路

核心文案：我们不是再做一个单词表，而是创造一个学生愿意反复进入的学习场景。

讲述重点：
- 词汇学习的关键不只是内容量，而是持续练习的意愿。
- 词汇森林用沉浸界面、主动回忆和即时反馈，把学习变得更可坚持。
- 它从一个轻量词汇工具开始，具备扩展为教育场景产品的潜力。
- 收束到产品愿景：让单词不再只是列表，而是学生每天走过的一条路。

视觉建议：
- 森林小路通向一本发光词书。
- 单词像种子一样在路边长成树。
- 结尾保留产品名和一句愿景文案。

## 附：演讲节奏建议

- 第 1-2 页：建立情绪记忆点和痛点，约 1 分钟。
- 第 3-6 页：讲清产品是什么、怎么用、为什么有效，约 3 分钟。
- 第 7-10 页：讲差异化、内容体系、技术基础和应用场景，约 2 分钟。
- 第 11-12 页：讲增长空间和愿景收束，约 1-2 分钟。
